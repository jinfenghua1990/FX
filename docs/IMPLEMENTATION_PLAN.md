## 开发原则

- 先让数据模型稳定，再做大规模 UI。
- 旺店通采购、库存、出库继续复用，不重复造 ERP。
- 任何外部接口先做沙盒/测试账号验证，再接生产账号。
- 订单推送必须可追踪、可重试、不可重复扣库存。
- 每完成一个阶段，都更新本文件和 `docs/PROJECT_CONTEXT.md`。
